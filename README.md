# CaffNap ☕🌙

**咖啡因宵禁 & 入睡预测 · 咖啡小睡教练**

基于药代动力学与昼夜节律双模型的咖啡因摄入规划工具：记录每一杯咖啡，预测你今晚最早几点能睡着，并反推「最后一杯的最晚时间」。

> 🌐 **在线使用**：`https://yhlhhhhh.github.io/caffnap/`
> 零安装、零依赖、数据仅存本机浏览器（localStorage），不上传任何服务器。

---

## ✨ 功能

| 功能 | 说明 |
|---|---|
| ☕ 摄入记录 | 多杯咖啡因记录（饮品类型 × 杯数 × 时间），自动按日归档 |
| 🧬 基因型档案 | CYP1A2 / ADORA2A / AHR / ABCG2 四个 SNP 位点 → 个性化半衰期与睡眠阈值 |
| 🕙 入睡预测 | 双条件判定：咖啡因血药浓度 ≤ 阈值 **且** 褪黑素达 DLMO，取较晚者 |
| 🚫 宵禁反推 | 输入目标入睡时间 → 输出「最后一杯最晚几点」，并提示换小杯能延后多少 |
| 😴 咖啡小睡 | 小睡结束晚于 15:00 自动计入入睡推迟；经典 coffee nap（≤20min）无夜间代价 |
| 📈 双曲线可视化 | 血药浓度叠加曲线 + 褪黑素节律曲线（含咖啡因相位延迟与分泌压制） |
| 🌗 暗色模式 | 自动跟随系统 |

## 🔬 模型

**药代动力学层**（一房室一级消除，多杯线性叠加）：

```
C(t) = Σ (mg / 42 L) × 1.15 × 2^(−Δt / t½)
```

- 半衰期由 **CYP1A2 rs762551** 主导：AA ≈ 3.2h / AC ≈ 4.5h / CC ≈ 7.5h
- AHR、ABCG2 每等位基因微调 ±5–10%；吸烟 ×0.7；口服避孕药/妊娠 ×1.5
- 睡眠阈值由 **ADORA2A rs5751876** 决定：TT 敏感 1.3 / CT 1.0 / CC 钝感 0.8 mg/L

**节律层**：

- DLMO（褪黑素起始上升点）锚定于 23:00 − 2h
- 18:00–01:00 摄入咖啡因 → 相位延迟 200mg ≈ 40min（上限 3h）
- 咖啡因在血期间压制褪黑素分泌幅度 30%

**判定**：最早可入睡 = max(咖啡因降至阈值, 褪黑素 ≥ 10 pg/mL) + 小睡推迟项
